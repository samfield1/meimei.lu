Exploring the home page

Login

When first logging into the app or creating an account, the user is greeted with a still from any Disney movie. The same goes for the home page. In the process of designing the app, I wanted to find a way to include the gorgeous illustrated backgrounds from older Disney movies. I couldn’t figure out another way asides from them being the background of the screen. But since there are an abundance of nonintrusive Disney stills, it ended up being a good way to set the tone for the app as well as showcase the art.

Home Page

The home page consists of a ‘feed’, where the user can view the movie reviews and ratings their friends have written. The friends’ usernames, rating, and review (if applicable) are present underneath a thumbnail of the movie they watched.
Exploring the section page
Search page

Search Page

Going to another page also changes the background still. If the still is a bit busy, like the still from Up, the yellow dialog which fades the image out a little ensures that the text is still readable. On the search page, there are categories through which you can browse if you are just leisurely looking.

Read Reviews

An essential part of this app is being able to read the reviews from all users on any given Disney movie. There is also a tab for the user to read only the reviews from people they follow.
Exploring other users' reviews
Write A Review

Write A Review

The process for writing a review and contributing the user’s own content into the app is very straightforward. They only need to give the movie a rating out of 5, and the written review is optional. The ‘contains spoilers’ feature is from Letterboxd, which is useful for preventing users from reading spoilers from movies they haven’t seen.

Profile and Notifications

The user’s profile page is where they can keep track of all the movies they’ve rated, reviews they’ve written, and other contributions or logged items, such as lists and likes. The notification page is where interactions get logged, such as other users liking your review, other users tagging you in a comment, or even just seeing the activity of the friends you follow.
